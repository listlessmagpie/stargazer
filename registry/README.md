# The registry: rules written before the data is looked at

Every test family in RESTART.md has a file here, dated, stating the rule, the markets, the
window, the expected direction and the minimum occasions, before the test that answers it is
run. A rule may be added. A rule is never edited after its test has run; if it was wrong, a new
dated rule says so and the old one stays.

This is stage 0 of the gate. Nothing moves pretend money without a file here, and nothing
moves real money without a file here, a stage 1 pass, and ten forward occasions on the paper
book.
